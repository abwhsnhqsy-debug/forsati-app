# فرصتي — النسخة المجمعة

هذه النسخة تحتوي على واجهة فرصتي المرتبطة بـ Supabase، مع الحسابات والوظائف والتقديم والرسائل والأجهزة والاشتراكات، وربط PayPal عبر Edge Functions.

## تشغيل الويب
افتح `www/index.html` أو استضف مجلد `www` على HTTPS.

## Android
المشروع مهيأ لـ Capacitor. من جهاز تطوير يحتوي Android SDK يمكن تشغيل:
`npm install`
ثم `npx cap add android` و `npx cap sync android` ثم بناء APK/AAB من Android Studio.

ملاحظة: بيئة التجميع الحالية لا تحتوي Android SDK، لذلك لم يتم الادعاء بوجود APK مبني من هذه الجلسة.
